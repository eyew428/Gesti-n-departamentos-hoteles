# Gesti-n-departamentos-hoteles
Aplicación de gestión de departamentos y hoteles

Una aplicación para la gestión de departamentos, tipo inmobiliaria.
Funcionalidades:
Registro de edificios
Registro de clientes
Relacionar cliente con edificio
Gestión de solicitud para un tiempo.
Entidades:
Clientes
Edificios
Alquiler
